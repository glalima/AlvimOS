# DOMÍNIO — CRM

## Objetivo
Transformar histórico de pedidos em comportamento e retenção.

## Cadeia
CLIENTE → PEDIDO → RECÊNCIA → FREQUÊNCIA → VALOR → SEGMENTO → AÇÃO → RETENÇÃO → LTV

## Estado conhecido
O banco possui:
- clientes;
- pedidos;
- estruturas de histórico;
- views CRM;
- fotografia diária.

## Direção
Manter CRM separado da lógica de estoque, conectando-os por eventos de venda e análise de rentabilidade/demanda.
